Sistema de Gestión de Hospital

Implementación de estructuras de datos en Java

Acerca del proyecto

Este sistema simula la gestión completa de un hospital o servicio de urgencias, implementando de manera integrada todas las estructuras de datos estudiadas en el curso de Estructura de Datos.

El proyecto demuestra el uso práctico de arrays, matrices, pilas, colas, listas simples, listas dobles, listas circulares y árboles binarios de búsqueda aplicados a un caso de uso real.

Estructuras de datos implementadas

Array

Especialidades y Triage

Almacena los tipos de especialidades médicas (Urgencias, Pediatría, Cirugía, etc.) y los niveles de triage del 1 al 5.

Matriz

Gestión de camas

Representa las camas del hospital organizadas por pisos (filas) y camas por piso (columnas). Indica si están libres, ocupadas o en mantenimiento.

Pila (Stack)

Historial médico

Guarda el historial de atención médica de los últimos pacientes atendidos. Permite deshacer la última atención registrada.

Cola (Queue)

Fila de espera

Maneja la fila de pacientes que esperan ser atendidos en urgencias, priorizados por orden de llegada o nivel de triage.

Lista Simple

Pacientes hospitalizados

Almacena los pacientes actualmente hospitalizados con su información básica: ID, nombre, diagnóstico y cama asignada.

Lista Doble

Registro de médicos

Registra los médicos del hospital, permitiendo recorrerlos hacia adelante y hacia atrás. Útil para asignación de turnos y búsqueda por especialidad.

Lista Circular

Turnos médicos

Almacena los turnos médicos (mañana, tarde, noche). Cuando termina la lista, vuelve al primer turno automáticamente.

Árbol Binario

Búsqueda rápida

Árbol binario de búsqueda que permite encontrar pacientes rápidamente por número de documento o historia clínica.

Funcionalidades principales

  • Ingreso y registro de pacientes en cola de espera
  • Asignación automática de camas disponibles
  • Registro de atención médica con médico asignado
  • Búsqueda rápida de pacientes por documento
  • Gestión de turnos médicos rotativos
  • Visualización del estado completo del hospital
  • Historial de atenciones con opción de deshacer
  • Estadísticas en tiempo real del hospital

Tecnologías utilizadas

Java 11 Maven HTML5 CSS3

Cómo ejecutar el proyecto

Compilar: mvn clean compile

Ejecutar: mvn exec:java -Dexec.mainClass="com.hospital.Main"

Empaquetar: mvn package
